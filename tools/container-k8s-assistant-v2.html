Referencia rápida

Pods

kubectl get pods -A -o wide kubectl describe pod POD -n NAMESPACE kubectl logs POD -n NAMESPACE

Nodes

kubectl get nodes -o wide kubectl describe node NODE kubectl top nodes

Networking

kubectl get svc -A kubectl get endpointslices -A kubectl get networkpolicy -A

Archivos

kubectl cp archivo NAMESPACE/POD:/tmp/ scp archivo usuario@worker:/tmp/
